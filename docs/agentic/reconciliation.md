# Reconciliation

## Objective
Ensure internal transaction records match external provider and settlement reports.

## Process outline
1. Collect internal and external datasets.
2. Normalize records for deterministic matching.
3. Match, classify, and record discrepancies.
4. Escalate unresolved mismatches.

## Controls
- Deterministic matching keys.
- Versioned matching logic.
- Audit records for mismatch classification.

## Outputs
- Matched summary
- Missing records list
- Mismatch report with reason codes
